# Support

- **Questions and how-to help:** open a discussion or an issue labelled "question".
- **Bugs:** use the bug report template, so the device model, Android version and steps are recorded.
- **Feature ideas:** use the feature request template.
- **Security issues:** see [SECURITY.md](SECURITY.md). Do not post them publicly.

Hohe is maintained by a small team. Response times are best effort.
