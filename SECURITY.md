# Security Policy

## Supported versions

Hohe is pre-release. Only the latest version on the default branch receives security fixes.

| Version | Supported |
|---|---|
| 0.1.x (latest) | Yes |
| Older | No |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub's private vulnerability reporting: **Security tab → Report a vulnerability** on this repository.

Include:

- the affected version or commit,
- steps to reproduce,
- the impact you expect, for example typed text leaving the device or a misuse of a permission.

Acknowledgement is best effort. Verified fixes ship in the next release, and the reporter is credited unless they ask not to be.

## Scope

In scope: the Hohe app, its build scripts, and the data files shipped in the app.
Out of scope: vulnerabilities in Android itself or in other keyboards.
