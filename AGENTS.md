# Hohe (ሆሄ)

Hohe is an offline-first Amharic and English Android keyboard (IME) focused on privacy, responsiveness, and clean typography. It provides fast, fluent typing in Geez script and Latin with zero tracking, no ads, and no typed data leaving the device.
